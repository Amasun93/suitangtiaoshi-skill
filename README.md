# suitangtiaoshi-skill

面向教师的课堂工作 Skill，包含学生项目素材批量整理、基于真实课堂观察的每日家长回课，以及学生答辩准备交接。老师不需要编写命令或提示词模板，只需提供材料或如实口述学生情况。

学生最终答辩由 `idealab-student-skills` 作为唯一入口完成；本 Skill 负责先把本地材料归档清楚并说明缺项，避免教师端和学生端维护两套不同规则。

## 老师怎么使用

安装后直接对 AI 说：

> 使用 `$suitangtiaoshi-skill` 整理这个素材文件夹。先识别学生和材料类型，给我预演清单，有不确定的地方再问我，不要直接移动或删除文件。

生成回课时可以直接说：

> 使用 `$suitangtiaoshi-skill` 生成今天D4的回课。公共课程内容按今天实际完成情况写，下面是每名学生的真实表现，请忠实润色，不要拔高事实。

也可以只口述一名学生的情况，让AI生成可替换到D1—D7公共模板中的个性化表现段落。

也可以直接把文件或文件夹附在对话里，并说明：

- 这是哪个班的材料。
- 正式档案放在哪里。
- 这批材料主要来自老师、学生还是混合来源。

不需要老师自己编写命令、JSON 或逐个重命名文件。

## 材料整理时AI应该怎么做

1. 读取本 Skill 的 `SKILL.md` 和 `references/archive-schema.json`。
2. 找到老师提供的素材目录、正式档案目录和学生项目清单。
3. 扫描材料，识别对应学生、项目、材料类别和建议文件名。
4. 先生成整理预演清单，不立即写入正式档案。
5. 把不确定项用简单中文选项询问老师。
6. 根据老师回答更新判断，并重新生成预演清单。
7. 汇总将复制、跳过重复和仍待确认的数量。
8. 只有老师明确确认后才正式归档。
9. 完成后检查结果，并说明每名学生新增了哪些材料、还有哪些缺项。

AI 不应把技术操作转交给老师。若需要修正规则，由 AI 自己生成覆盖文件并重新预演。

## AI 需要询问的情况

- 文件无法唯一对应某名学生。
- 一个学生存在多个相近项目名称。
- 图片无法判断是功能、实验、原型还是制作过程。
- 视频无法判断是老师讲解版还是学生正式版。
- PPT 无法判断是开题方案还是答辩 PPT。
- 文件名与内容、目录或项目明显冲突。

同类问题应合并询问。例如：

> 这 6 段视频都来自老师预开发材料包。是否统一作为“老师讲解版”归档？

不要连续询问 6 次相同问题。

## 整理结果

每名学生使用以下档案：

```text
随堂调试-学生姓名-项目名称/
├─ 01 开题书/
├─ 02 学生项目手册/
├─ 03 项目图纸/
├─ 04 项目代码/
├─ 05 项目关键性图片/
├─ 06 答辩材料/              # 答辩PPT与答辩视频
├─ 07 项目视频/
├─ 08 项目装置交接单/
├─ 09 可选-学生论文/
├─ 10 研究日志/
└─ 99 待确认/
```

Skill 会保存预演清单、SHA-256 去重结果和每名学生的归档操作记录。

## 安全规则

- 只复制，不移动或删除源文件。
- 不覆盖已有材料。
- 相同内容不重复复制。
- 未确认的学生归属不写入正式档案。
- 未明确确认前不执行正式归档。
- “已经归档”不代表“质量验收通过”。
- 学生名单、项目材料和密钥不应上传到 Skill 仓库。

## 安装

Codex 用户可将仓库放入：

```text
~/.codex/skills/suitangtiaoshi-skill/
```

其他支持 Skill 的 AI 工具应安装整个仓库，并确保 AI 能读取根目录的 `SKILL.md`、运行 Node.js 20 或更高版本。

## 给 AI 的命令参考

通常由 AI 自动执行，老师不需要手动输入。

```bash
# 生成预演
node scripts/organize-materials.mjs plan --intake "待整理素材" --archive-root "项目交付档案" --roster "学生项目清单.json" --origin unknown --output "整理预演.json"

# 老师确认后正式归档
node scripts/organize-materials.mjs apply --plan "整理预演.json" --confirm

# 检查档案缺项
node scripts/organize-materials.mjs audit --archive-root "项目交付档案" --roster "学生项目清单.json" --output "档案检查.json"
```

材料整理模块负责命名、复制、去重、记录和缺项检查。图片质量、视频清晰度、项目事实和最终验收仍由老师确认。

## 每日回课

- 保留D1—D7公共回课模板，按当天真实课堂情况调整。
- 老师口述学生表现后，AI只整理语言，不改变完成程度和责任边界。
- 姓名以正式名单为准；不把同音字、生僻字自动改成常见姓名。
- 个性化反馈应包含具体进展、可观察行为、肯定和必要的改进建议，不能只写空泛表扬。
- 老师提到分心、耐心不足或依赖提醒时，使用客观、柔和的行为描述，不删除这些信息，也不给学生贴标签。
- 未经确认，不写“功能达标”“完整实现”“独立完成”或进度百分比。
- 默认只输出草稿，不自动发送家长群，也不自动写入学生档案。

## 给同事的使用说明

这个 Skill 主要解决两件事：

1. 把老师、学生和课堂收集来的项目材料整理到每名学生的一套正式档案中。
2. 根据老师当天的真实观察，生成每日家长回课草稿。

它适合由老师把一个素材文件夹直接交给 AI，也适合老师只用自然语言口述学生表现。老师不需要自己编写 JSON、批量改名或设计提示词。

### 整理材料时这样说

> 使用 `$suitangtiaoshi-skill` 整理这个素材文件夹。先识别学生和材料类型，给我预演清单；有不确定的地方集中问我，不要直接移动或删除文件。

最好同时告诉 AI：

- 这是哪个班的材料。
- 正式档案要放在哪个目录。
- 学生名单或学生—项目清单在哪里。
- 材料来自老师、学生，还是混合来源。

完整流程是：扫描 → 识别 → 生成预演 → 集中询问不确定项 → 老师确认 → 复制归档 → 检查缺项。第一次运行不会直接写入正式档案。

### 生成回课时这样说

> 使用 `$suitangtiaoshi-skill` 生成今天 D4 的回课。公共课程内容按今天实际完成情况写，下面是每名学生的真实表现，请忠实润色，不要拔高事实。

也可以只说：

> 请把这段课堂观察润色成家长回课，只写确认过的事实，保留老师帮助和学生还需要改进的地方。

回课支持完整班级回课、单名学生表现润色和批量生成。默认只输出草稿，不自动发家长群，也不自动写入档案。

## 当前能实现与暂时不能实现

| 事项 | 当前状态 | 说明 |
|---|---|---|
| 扫描素材文件夹 | 已实现 | 递归识别文件，忽略临时文件和符号链接 |
| 学生/项目匹配 | 已实现 | 支持正式姓名、别名和项目别名；不唯一时待确认 |
| 材料分类 | 已实现 | 根据路径、文件名、扩展名和人工覆盖规则判断 |
| 归档预演 | 已实现 | 输出 JSON 计划和 Markdown 摘要 |
| 安全复制归档 | 已实现 | 必须明确确认，脚本不移动、不删除源文件 |
| SHA-256 去重 | 已实现 | 相同内容不重复复制 |
| 代码目录保留 | 已实现 | 保留项目代码和研究日志的内部结构 |
| 同名冲突处理 | 已实现 | 不覆盖已有文件，自动生成版本名 |
| 归档缺项检查 | 已实现 | 检查目录、必需材料、待确认项和重复组 |
| 图片/视频质量判断 | 未自动实现 | 需要老师人工查看清晰度、内容和学生是否出镜 |
| 项目功能真实性验证 | 未自动实现 | 文件存在不等于项目运行成功 |
| 学生独立调试判断 | 未自动实现 | 需要单独的随堂审核和演示证据 |
| D1—D7 公共回课 | 已实现为规则模板 | 必须用当天真实完成情况覆盖模板 |
| 个性化回课润色 | 已实现为 AI 工作流 | 只整理语言，不增加事实强度 |
| 自动发送家长消息 | 不实现 | 默认只生成草稿 |
| 自动写入学生档案 | 不实现 | 需要老师另行明确授权 |
| 自动评分和绩效计算 | 不实现 | 不属于本 Skill 的职责 |

“已归档”只表示文件完成了整理和复制，不表示项目已经通过功能验收。

## 与随堂审核 Skill 的区别

本 Skill 负责收材料、分类、去重、归档、缺项提示和家长回课。

`audit-student-class-debugging` 是另一个 Skill，负责检查学生是否独立演示、功能是否与开题材料一致、验收证据是否完整，以及是否需要复审。不要把材料整理结果当作审核通过。

## 给 AI 的安全边界

- 不上传学生名单、照片、视频、项目代码或密钥到 Skill 仓库。
- 不猜测学生归属、材料类别、完成程度或实验结论。
- 同类不确定项合并询问，不要逐个重复打扰老师。
- 保留“老师帮助”“AI 辅助”和“尚未完成”等责任边界。
- 归档、回课和验收是三个不同判断：材料存在、文字写好、项目通过不能互相替代。

## 安装和验证

Codex 用户可将整个仓库放入：

```text
~/.codex/skills/suitangtiaoshi-skill/
```

命令行归档脚本需要 Node.js 20 或更高版本。仓库根目录运行：

```bash
npm run validate
```

该命令会检查脚本语法并运行材料整理测试。当前自动测试覆盖预演、安全复制、代码目录保留和重复文件识别；回课部分主要由 `SKILL.md`、`references/daily-parent-feedback.md` 和 `references/seven-day-feedback-templates.md` 约束。
